# Neuer AI — نوير للذكاء الاصطناعي

Neuer AI مساحة محادثة عربية جاهزة للاستخدام. **المسار الافتراضي Neuer AI يعمل مباشرة دون أن يطلب من المستخدم مفتاح API أو تثبيت Ollama أو إعدادًا تقنيًا.**

## ما يعمل مباشرة

- محادثة عربية حقيقية عبر خدمة الذكاء الاصطناعي المدمجة في خادم المشروع.
- ردود Markdown، إعادة التوليد، تعديل وحذف ونسخ الرسائل.
- حفظ المحادثات محليًا في المتصفح مع بحث وإعادة تسمية وتصدير واستيراد.
- قراءة ملفات TXT وMarkdown وCSV وJSON وPDF داخل المتصفح قبل إرسالها.
- بحث ويكيبيديا العربي والإنجليزي من مركز الأدوات المجانية.
- إملاء صوتي وقراءة الردود صوتيًا حسب دعم المتصفح.
- واجهة عربية RTL متجاوبة، وضع داكن/فاتح، وقائمة هاتف واضحة.

## طريقة الاستخدام

1. افتح الرابط العام.
2. اكتب رسالتك في المحرر.
3. اضغط «إرسال» أو Enter.

المزوّد المختار افتراضيًا هو `Neuer AI · جاهز`، ويظهر في الشاشة كـ «جاهز بلا مفتاح». Ollama وOpenRouter وGroq موجودة كمسارات اختيارية متقدمة فقط، ولا تؤثر على المسار الافتراضي.

## التطوير

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build
```

الخادم يعرّف `POST /api/ai/chat` و`GET /api/health`. أسرار المنصة تُقرأ على الخادم فقط ولا تُرسل إلى المتصفح.

## الخصوصية

المحادثات المحلية تُحفظ في متصفح المستخدم. الملفات تُقرأ محليًا ولا تُرسل إلا عندما يضغط المستخدم على إرسال. لا توجد مفاتيح مشتركة في الكود أو الواجهة.
